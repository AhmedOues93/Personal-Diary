# 📝 Personal Diary App

A simple personal diary application built with **React**, styled using **Tailwind CSS** and **DaisyUI**, and using **localStorage** to save entries directly in the browser.

## 🚀 Live Demo

🔗 [Check out the live app on Netlify](https://meek-swan-8e0db1.netlify.app/)

## 🛠️ Technologies Used

- ⚛️ **React** – for building a reactive and component-based user interface.
- 🎨 **Tailwind CSS** – for fast and responsive styling.
- 🌼 **DaisyUI** – UI components built on top of Tailwind for easy styling.
- 💾 **localStorage** – to store diary entries locally without the need for a backend.
- ⚡ **Vite** – a modern and fast development environment.

## 📦 Features

- Add new diary entries with **title**, **date**, **image**, and **content**.
- Display all entries as stylish **cards**.
- Delete any diary entry.
- Responsive and clean user interface.
- Data persistence using browser’s localStorage.
